<p id="description">
Playbox is a JavaScript-focused course assignment where the main objective was to work with APIs, dynamic content rendering, and application structure using an MVC (Model-View-Controller) approach.  
The design is inspired by modern gaming platforms such as Steam and GameStop.
</p>

<h2>🚀 Live Demo</h2>
👉 https://rebeckakinn.github.io/JS1_Course_Assignment/

<h2>📖 About the Project</h2>
<p>
Playbox is a Single Page Application (SPA) that fetches product data from the Noroff API and dynamically renders content using JavaScript.
</p>
<p>The project focuses on:</p>

<ul>
  <li>Fetching and handling API data</li>
  <li>Structuring JavaScript using MVC architecture</li>
  <li>DOM manipulation and dynamic rendering</li>
  <li>Local Storage for simulated cart and purchase history</li>
  <li>State handling without page reload</li>
</ul>

<p>
This assignment marked an important transition from static HTML/CSS projects to fully dynamic JavaScript-driven applications.
</p>


<h2>🧐 Key Features</h2>
<ul>
  <li>🔗 Fetches product data from the Noroff API</li>
  <li>🛒 Simulated shopping cart using Local Storage</li>
  <li>📦 Purchase history stored locally</li>
  <li>🔄 Single Page Application behavior</li>
  <li>🧠 MVC-based project structure</li>
  <li>🎮 Modern gaming-inspired UI</li>
</ul>

<h2>🛠️ Installation</h2>
1. Clone the repository:
</br>
```
git clone https://github.com/RebeckaKinn/JS1_Course_Assignment.git
```
</br>
2. Navigate into the project folder:
</br>
```
cd JS1_Course_Assignment
```
</br>
3. Open index.html in your browser
<p>(or use Live Server in VS Code)</p>
<p>No build tools or frameworks required.</p>

<h2>📂 Project Structure</h2>
<ul>
  <li><strong>Model</strong> – Handles API requests and manages data</li>
  <li><strong>View</strong> – Renders UI components and layout</li>
  <li><strong>Controller</strong> – Handles user interaction and connects Model + View</li>
</ul>
<p>This MVC-inspired structure makes the project easier to maintain, scale, and understand.</p>
